# UNE11D07 — Ejercicio guiado de modelos y tipos de campos

Clase 7 del Nivel 11 — Python IV: Django.

- **Práctica:** Ejercicio guiado de modelos y tipos de campos
- **Resultado terminado:** Catálogo de productos con modelo, formulario, vista y administración.
- **Herramientas:** Python, Django ORM, formularios y admin y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
