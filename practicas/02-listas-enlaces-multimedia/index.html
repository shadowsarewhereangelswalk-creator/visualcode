Una guía sencilla para organizar mi práctica de programación.

Ver recursos adicionales Consultar MDN

Herramientas necesarias

  • Visual Studio Code
  • Un navegador web
  • Una carpeta para el proyecto

Pasos para practicar

  1. Crear el archivo index.html.
  2. Escribir la estructura HTML5.
  3. Guardar el archivo.
  4. Abrirlo en el navegador.
  5. Revisar el resultado.

Conceptos importantes

HTML
Lenguaje que organiza el contenido de una página web.
Etiqueta
Elemento que indica la función de cada parte del contenido.
Ruta relativa
Dirección de un archivo calculada desde la ubicación del documento actual.
