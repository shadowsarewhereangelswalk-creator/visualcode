# UNE2D12 — article, aside y organización del contenido

Clase 12 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar `<article>` y `<aside>` dentro de una estructura semántica.
- **Conceptos:** contenido independiente, contenido complementario y organización de una página.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Separar el contenido principal de un artículo y la información complementaria de un aside.
- **Archivo:** `index.html`.

Abre `index.html` y observa la relación entre `main`, `article` y `aside`.
