# UNE12D20 — Fundamentos de requirements.txt y gestión de dependencias

Clase 20 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Fundamentos de requirements.txt y gestión de dependencias
- **Resultado terminado:** Analizador de dependencias y restricciones desde requirements.txt.
- **Herramientas:** Packaging, requirements y pytest y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements-dev.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
