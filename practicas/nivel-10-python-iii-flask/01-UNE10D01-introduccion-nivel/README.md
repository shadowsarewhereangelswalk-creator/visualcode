# UNE10D01 — Introducción al Nivel 10: objetivos, herramientas y proyecto del mes

Clase 1 del Nivel 10 — Python III: Flask.

- **Práctica:** Introducción al Nivel 10: objetivos, herramientas y proyecto del mes
- **Resultado terminado:** Panel web y endpoint JSON con el plan completo del nivel.
- **Herramientas:** Python, Flask y Visual Studio Code
- **Proyecto del nivel:** Servicio Flask

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python app.py`.

Comprueba la estructura y la lógica independiente con `python app.py --check`.
