# Práctica HTML 1 — Página con etiquetas básicas de texto

Esta práctica corresponde a **UNE2D09 — Práctica P1**.

## Objetivo

Crear una página HTML sencilla y aplicar correctamente la jerarquía de encabezados, los párrafos, el texto importante, el énfasis y los comentarios.

## Archivo que debes usar

Abre [index.html](index.html) en Visual Studio Code.

## Instrucciones

Dentro de <code>&lt;body&gt;</code>, escribe una página sobre tu aprendizaje en AI Career que incluya:

1. Un solo encabezado <code>&lt;h1&gt;</code> con el tema principal.
2. Al menos dos secciones con <code>&lt;h2&gt;</code>.
3. Una subsección con <code>&lt;h3&gt;</code>.
4. Tres o más párrafos con <code>&lt;p&gt;</code>.
5. Una frase importante marcada con <code>&lt;strong&gt;</code>.
6. Una palabra o frase con énfasis usando <code>&lt;em&gt;</code>.
7. Un comentario HTML que no aparezca en el navegador.

## Reglas

- Escribe el contenido con tus propias palabras.
- No uses CSS ni JavaScript en esta práctica.
- Elige los encabezados por su jerarquía, no por el tamaño que muestran.
- Guarda con <kbd>Ctrl</kbd> + <kbd>S</kbd> y abre el archivo en el navegador.

## Comprobación

Antes de entregar, confirma:

- [ ] Hay un solo <code>&lt;h1&gt;</code>.
- [ ] Los <code>&lt;h2&gt;</code> dependen del tema principal.
- [ ] El <code>&lt;h3&gt;</code> pertenece a una sección.
- [ ] Hay al menos tres párrafos.
- [ ] Utilizaste <code>&lt;strong&gt;</code> y <code>&lt;em&gt;</code> correctamente.
- [ ] El comentario HTML no se ve en la página.
- [ ] El navegador muestra el contenido sin errores.

## Entrega

Comparte el código terminado o una captura del navegador para revisarlo. Este repositorio contiene el punto de inicio, no la solución.
