# UNE12D21 — Fundamentos de Git: commits, ramas y merges

Clase 21 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Fundamentos de Git: commits, ramas y merges
- **Resultado terminado:** Programa que crea un repositorio real, dos ramas, commits y un merge.
- **Herramientas:** Git, pytest y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
