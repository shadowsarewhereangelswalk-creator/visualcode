# UNE11D08 — Práctica P1: proyecto Django con modelos y migraciones

Clase 8 del Nivel 11 — Python IV: Django.

- **Práctica:** Práctica P1: proyecto Django con modelos y migraciones
- **Resultado terminado:** Biblioteca con autores, libros, formularios, plantillas y migración inicial.
- **Herramientas:** Python, Django ORM y migraciones y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
