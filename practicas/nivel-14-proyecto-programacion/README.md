# Nivel 14 — Proyecto en Programación

Prácticas construidas a partir de `Plan_Estudio_AI_Career_Tracker` → `Plan_Clases`.

Cada carpeta corresponde a una clase UNE14D01–UNE14D31. El código funciona como solución de referencia del proyecto final; la evidencia de despliegue, presentación y evaluación se registra fuera del repositorio cuando corresponda.

- [UNE14D22 — P3: backend funcional conectado a base de datos](22-UNE14D22-practica-p3-backend-db/main.py)
- [UNE14D26 — P4: integración de una función con IA](26-UNE14D26-practica-p4-funcion-ia/main.py)
- [UNE14D30 — P5: aplicación final integrada y preparada para despliegue y presentación](30-UNE14D30-practica-p5-proyecto-final/main.py)
