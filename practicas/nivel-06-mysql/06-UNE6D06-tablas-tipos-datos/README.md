# UNE6D06 — Fundamentos de creación de tablas y tipos de datos

Clase 6 del Nivel 6 — MySQL.

- **Objetivo:** Comprender y aplicar fundamentos de creación de tablas y tipos de datos dentro del objetivo del Nivel 6.
- **Conceptos:** Fundamentos de creación de tablas y tipos de datos
- **Herramientas:** MySQL, MySQL Workbench, SQL
- **Proyecto del nivel:** Base de datos para aplicación real
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de creación de tablas y tipos de datos.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en MySQL Workbench y ejecuta todo el script. El archivo recrea únicamente la base `une6d06_types` e incluye estructura, datos y consultas de comprobación terminadas.
