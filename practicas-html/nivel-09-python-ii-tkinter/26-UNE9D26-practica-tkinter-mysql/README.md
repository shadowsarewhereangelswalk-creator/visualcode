# UNE9D26 — Práctica P4: conexión de una interfaz Tkinter a MySQL

Clase 26 del Nivel 9 — Python II: Tkinter.

- **Objetivo:** Completar práctica p4: conexión de una interfaz tkinter a mysql y demostrar los conocimientos acumulados.
- **Conceptos:** Práctica P4: conexión de una interfaz Tkinter a MySQL
- **Herramientas:** Python, Tkinter, MySQL y Visual Studio Code
- **Proyecto del nivel:** CRUD de escritorio
- **Ejercicio:** Ejecutar y comprobar la aplicación terminada de práctica p4: conexión de una interfaz tkinter a mysql.
- **Entregable:** Aplicación funcional de práctica p4: conexión de una interfaz tkinter a mysql.
- **Archivos:** `main.py`, `database.sql`, `requirements.txt`

1. Ejecuta `database.sql` en MySQL.
2. Instala la dependencia con `python -m pip install -r requirements.txt`.
3. Configura `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` y `MYSQL_DATABASE` si tus valores son diferentes.
4. Ejecuta `python main.py`.

Puedes verificar la lógica sin abrir la ventana con `python main.py --check`.
