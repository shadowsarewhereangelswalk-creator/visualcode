# UNE2D20 — Controles: radio, checkbox, select y textarea

Clase 20 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar controles habituales de formularios.
- **Conceptos:** `radio`, `checkbox`, `<select>`, `<option>` y `<textarea>`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Crear un formulario con selección única, selección múltiple, lista desplegable y texto libre.
- **Archivo:** `index.html`.

Abre `index.html` y compara cómo se captura la información con cada tipo de control.
