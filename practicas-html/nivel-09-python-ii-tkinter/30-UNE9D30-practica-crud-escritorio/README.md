# UNE9D30 — Práctica P5: proyecto de aplicación CRUD de escritorio completa

Clase 30 del Nivel 9 — Python II: Tkinter.

- **Objetivo:** Completar práctica p5: proyecto de aplicación crud de escritorio completa y demostrar los conocimientos acumulados.
- **Conceptos:** Práctica P5: proyecto de aplicación CRUD de escritorio completa
- **Herramientas:** Python, Tkinter, MySQL y Visual Studio Code
- **Proyecto del nivel:** CRUD de escritorio
- **Ejercicio:** Ejecutar y comprobar la aplicación terminada de práctica p5: proyecto de aplicación crud de escritorio completa.
- **Entregable:** Aplicación funcional de práctica p5: proyecto de aplicación crud de escritorio completa.
- **Archivos:** `main.py`, `database.py`, `modelos.py`, `database.sql`, `requirements.txt`

1. Ejecuta `database.sql` en MySQL.
2. Instala la dependencia con `python -m pip install -r requirements.txt`.
3. Configura `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` y `MYSQL_DATABASE` si tus valores son diferentes.
4. Ejecuta `python main.py`.

Puedes verificar la lógica sin abrir la ventana con `python main.py --check`.
