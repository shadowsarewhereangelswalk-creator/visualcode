# UNE12D13 — Fundamentos de formateo automático de código

Clase 13 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Fundamentos de formateo automático de código
- **Resultado terminado:** Generador de reportes con formato automático reproducible.
- **Herramientas:** Black, pytest y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Ejecuta `black --check .` para comprobar el formato.

Comprueba la estructura con `python app.py --check`.
