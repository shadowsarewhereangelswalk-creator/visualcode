# UNE11D15 — Práctica P2: CRUD completo usando el ORM de Django

Clase 15 del Nivel 11 — Python IV: Django.

- **Práctica:** Práctica P2: CRUD completo usando el ORM de Django
- **Resultado terminado:** Agenda con creación, consulta, edición y eliminación de contactos.
- **Herramientas:** Python, Django ORM y formularios y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
