# UNE2D19 — Campos input: text, email, password, number y date

Clase 19 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar distintos tipos de campos `input`.
- **Conceptos:** `text`, `email`, `password`, `number` y `date`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Construir un formulario que muestre el comportamiento de cinco tipos de input.
- **Archivo:** `index.html`.

Abre `index.html` y compara el tipo de dato y la interfaz que ofrece el navegador para cada campo.
