# UNE11D13 — Fundamentos de ORM de Django: consultas y filtros

Clase 13 del Nivel 11 — Python IV: Django.

- **Práctica:** Fundamentos de ORM de Django: consultas y filtros
- **Resultado terminado:** Buscador de ofertas laborales con filtros combinados y expresiones Q.
- **Herramientas:** Python, Django ORM y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
