# UNE12D22 — Práctica P3: repositorio Git con flujo de ramas y pull requests

Clase 22 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Práctica P3: repositorio Git con flujo de ramas y pull requests
- **Resultado terminado:** Flujo reproducible de rama, cambios, revisión, pruebas y fusión.
- **Herramientas:** Git, pytest y GitHub y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
