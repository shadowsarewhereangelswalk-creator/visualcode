# UNE7D05 — Ejercicio guiado de instalación y configuración de PostgreSQL

Clase 5 del Nivel 7 — PostgreSQL.

- **Objetivo:** Comprender y aplicar ejercicio guiado de instalación y configuración de postgresql dentro del objetivo del Nivel 7.
- **Conceptos:** Ejercicio guiado de instalación y configuración de PostgreSQL
- **Herramientas:** PostgreSQL, psql, pgAdmin, SQL
- **Proyecto del nivel:** Migración a PostgreSQL
- **Ejercicio:** Realizar un ejemplo guiado de ejercicio guiado de instalación y configuración de postgresql.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en pgAdmin o ejecútalo con psql. El archivo recrea únicamente el esquema `une7d05_configuration` e incluye estructura, datos y consultas de comprobación terminadas.
