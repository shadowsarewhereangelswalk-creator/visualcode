# UNE3D21 — Fundamentos de principios de diseño web responsive

Clase 21 del Nivel 3 — HTML5 y CSS3 Nivel II.

- **Objetivo:** Comprender y aplicar fundamentos de principios de diseño web responsive dentro del objetivo del Nivel 3.
- **Conceptos:** Fundamentos de principios de diseño web responsive
- **Herramientas:** HTML5, CSS3, VS Code, navegador
- **Proyecto del nivel:** Sitio web responsive
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de principios de diseño web responsive.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `index.html` y `styles.css`

La carpeta contiene un ejemplo completo y funcional. Abre `index.html` en el navegador para ejecutar la clase.
