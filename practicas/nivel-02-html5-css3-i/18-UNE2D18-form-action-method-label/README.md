# UNE2D18 — Formularios: form, action, method y label

Clase 18 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar la estructura básica de un formulario HTML.
- **Conceptos:** `<form>`, `action`, `method`, `<label>`, relación `for`/`id` y botón de envío.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Crear un formulario sencillo que envía sus datos mediante el método GET a la misma página.
- **Archivo:** `index.html`.

Abre `index.html`, completa los campos y pulsa Enviar. Observa los parámetros añadidos a la URL por el método GET.
