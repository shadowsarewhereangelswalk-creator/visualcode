# UNE2D08 — Rutas relativas, absolutas y organización de carpetas

Clase 8 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar rutas relativas, absolutas y organización de carpetas.
- **Conceptos:** rutas absolutas, rutas relativas, subcarpetas, `./` y `../`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Navegar entre archivos situados en distintas carpetas y distinguir enlaces internos relativos de enlaces externos absolutos.
- **Archivos:** `index.html`, `paginas/contacto.html` y `recursos/guia.html`.

Abre `index.html` en el navegador y recorre los enlaces. Observa cómo cambia la ruta según la carpeta en la que se encuentra cada archivo.
