# UNE10D26 — Práctica P4: librería propia publicada en modo de prueba

Clase 26 del Nivel 10 — Python III: Flask.

- **Práctica:** Práctica P4: librería propia publicada en modo de prueba
- **Resultado terminado:** Paquete reutilizable de utilidades Flask listo para construir y verificar.
- **Herramientas:** Python, Flask y Visual Studio Code
- **Proyecto del nivel:** Servicio Flask

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python -m pytest`.
4. Ejecuta `python -m build`.
5. Ejecuta `python -m twine check dist/*`.
6. Ejecuta `python app.py` para probar la librería dentro de Flask.

Comprueba la estructura y la lógica independiente con `python app.py --check`.
