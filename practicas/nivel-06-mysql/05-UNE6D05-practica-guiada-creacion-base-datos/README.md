# UNE6D05 — Ejercicio guiado de creación de bases de datos

Clase 5 del Nivel 6 — MySQL.

- **Objetivo:** Comprender y aplicar ejercicio guiado de creación de bases de datos dentro del objetivo del Nivel 6.
- **Conceptos:** Ejercicio guiado de creación de bases de datos
- **Herramientas:** MySQL, MySQL Workbench, SQL
- **Proyecto del nivel:** Base de datos para aplicación real
- **Ejercicio:** Realizar un ejemplo guiado de ejercicio guiado de creación de bases de datos.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en MySQL Workbench y ejecuta todo el script. El archivo recrea únicamente la base `une6d05_academy` e incluye estructura, datos y consultas de comprobación terminadas.
