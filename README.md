# Prácticas de programación — AI Career

Repositorio de soluciones de referencia para las prácticas del diplomado de Programación Full Stack con Python e IA, organizadas según `Plan_Estudio_AI_Career_Tracker` → `Plan_Clases`.

La carpeta oficial es [`practicas/`](practicas/README.md). Los ejercicios contienen código terminado, sin comentarios ni espacios pendientes. Las prácticas que dependen de bases de datos, APIs de IA, servicios externos o despliegue pueden requerir variables de entorno, dependencias o infraestructura adicional indicada por cada nivel.

El código de este repositorio no modifica el estado académico del tracker. Un ejercicio ejecutado correctamente no significa que una clase haya sido marcada como completada.
