# Práctica HTML 1 — Página con etiquetas básicas de texto

Esta práctica corresponde a **UNE2D09 — Práctica P1**.

## Objetivo

Crear una página HTML completa que utilice correctamente:

- Un encabezado principal con <code>&lt;h1&gt;</code>.
- Encabezados de sección con <code>&lt;h2&gt;</code>.
- Una subsección con <code>&lt;h3&gt;</code>.
- Párrafos con <code>&lt;p&gt;</code>.
- Texto importante con <code>&lt;strong&gt;</code>.
- Texto con énfasis mediante <code>&lt;em&gt;</code>.
- Una estructura HTML5 completa.

## Código terminado

[Abre el archivo index.html](index.html).

El archivo está listo para abrirse directamente en Visual Studio Code y en el navegador. No contiene comentarios, CSS ni JavaScript.
