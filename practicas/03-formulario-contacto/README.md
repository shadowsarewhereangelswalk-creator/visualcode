# Práctica HTML 3 — Formulario de contacto

Esta práctica corresponde a **UNE2D22 — Práctica P3**.

## Contenido

El formulario completo incluye:

- Etiquetas asociadas a cada campo.
- Campos de texto, correo, teléfono y fecha.
- Menú desplegable.
- Opciones de selección única.
- Casilla de aceptación.
- Área para escribir un mensaje.
- Validaciones nativas de HTML5.
- Botones para enviar y limpiar.

## Archivo terminado

[Abre index.html](index.html).

El formulario demuestra la estructura y validación del lado del navegador. Para enviar los datos a un servicio real sería necesario conectarlo posteriormente a un backend.
