# UNE12D09 — Fundamentos de fixtures, parametrización y mocks

Clase 9 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Fundamentos de fixtures, parametrización y mocks
- **Resultado terminado:** Servicio de recordatorios probado con fixtures, datos parametrizados y cliente simulado.
- **Herramientas:** pytest, fixtures y mocks y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
