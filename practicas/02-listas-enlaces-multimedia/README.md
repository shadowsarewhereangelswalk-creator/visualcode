# Práctica HTML 2 — Listas, enlaces y multimedia

Esta práctica corresponde a **UNE2D13 — Práctica P2**.

## Contenido

- Lista desordenada con <code>&lt;ul&gt;</code>.
- Lista ordenada con <code>&lt;ol&gt;</code>.
- Lista de descripción con <code>&lt;dl&gt;</code>.
- Enlace interno, enlace externo y enlace de regreso.
- Imagen local con texto alternativo y dimensiones.
- Contenido multimedia integrado mediante <code>&lt;iframe&gt;</code>.
