# UNE2D21 — Validación HTML5: required, minlength, maxlength y pattern

Clase 21 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar validación nativa de formularios con HTML5.
- **Conceptos:** `required`, `minlength`, `maxlength` y `pattern`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Validar campos obligatorios, longitud de texto y un formato definido mediante una expresión regular.
- **Archivo:** `index.html`.

Abre `index.html`, prueba datos válidos e inválidos y observa los mensajes de validación que muestra el navegador antes de permitir el envío.
