Las cinco prácticas principales corresponden a las clases 8, 15, 20, 26 y 30. El proyecto final es una aplicación CRUD de escritorio con una interfaz Tkinter y persistencia en MySQL.

Todas las clases incluyen `main.py` y un modo de comprobación con `python main.py --check`. Las clases 26 a 30 incluyen el esquema MySQL y su archivo de dependencias. La clase 31 añade pruebas automatizadas.
