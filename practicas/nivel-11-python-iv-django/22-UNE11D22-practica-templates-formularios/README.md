# UNE11D22 — Práctica P3: sistema de plantillas y formularios en Django

Clase 22 del Nivel 11 — Python IV: Django.

- **Práctica:** Práctica P3: sistema de plantillas y formularios en Django
- **Resultado terminado:** Reservas con herencia de plantillas, mensajes y validación de fecha.
- **Herramientas:** Python, Django, templates y formularios y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
