# UNE9D28 — Fundamentos de CRUD: UPDATE y DELETE desde la interfaz

Clase 28 del Nivel 9 — Python II: Tkinter.

- **Objetivo:** Comprender y aplicar fundamentos de crud: update y delete desde la interfaz dentro del objetivo del Nivel 9.
- **Conceptos:** Fundamentos de CRUD: UPDATE y DELETE desde la interfaz
- **Herramientas:** Python, Tkinter, MySQL y Visual Studio Code
- **Proyecto del nivel:** CRUD de escritorio
- **Ejercicio:** Ejecutar y comprobar la aplicación terminada de fundamentos de crud: update y delete desde la interfaz.
- **Entregable:** Aplicación funcional de fundamentos de crud: update y delete desde la interfaz.
- **Archivos:** `main.py`, `database.sql`, `requirements.txt`

1. Ejecuta `database.sql` en MySQL.
2. Instala la dependencia con `python -m pip install -r requirements.txt`.
3. Configura `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` y `MYSQL_DATABASE` si tus valores son diferentes.
4. Ejecuta `python main.py`.

Puedes verificar la lógica sin abrir la ventana con `python main.py --check`.
