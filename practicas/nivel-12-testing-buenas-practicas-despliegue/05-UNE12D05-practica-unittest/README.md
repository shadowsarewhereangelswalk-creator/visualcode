# UNE12D05 — Ejercicio guiado de pruebas unitarias con unittest

Clase 5 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Ejercicio guiado de pruebas unitarias con unittest
- **Resultado terminado:** Cuenta bancaria con preparación de casos, subpruebas y validación de errores.
- **Herramientas:** unittest y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Ejecuta `python -m unittest discover` para comprobar la práctica con unittest.

Comprueba la estructura con `python app.py --check`.
