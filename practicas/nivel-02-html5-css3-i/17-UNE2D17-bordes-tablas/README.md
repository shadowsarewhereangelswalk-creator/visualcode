# UNE2D17 — Bordes y presentación inicial de tablas

Clase 17 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar una presentación inicial a una tabla mediante CSS.
- **Conceptos:** bordes, `border-collapse`, espaciado interno y alineación de celdas.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Partir de una tabla HTML y mejorar su legibilidad con reglas CSS básicas.
- **Archivo:** `index.html`.

Abre `index.html` y observa cómo los estilos cambian la presentación sin modificar la estructura de filas y celdas.
