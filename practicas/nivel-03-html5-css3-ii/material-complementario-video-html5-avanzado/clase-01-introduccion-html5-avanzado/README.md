# UNE3C01 — Introducción a HTML5 avanzado

Ejercicio independiente de la clase complementaria 1.

## Objetivo
Repasar la estructura base de HTML5 y preparar el entorno de trabajo.

## Ejercicio
1. Abre `index.html`.
2. Identifica doctype, html, head, body, meta charset, viewport y title.
3. Cambia el título y el contenido principal.
4. Añade una sección que explique la relación HTML5–CSS3–JavaScript.
5. Comprueba el documento en el navegador.

## Entregable
Documento HTML5 válido y explicación breve de la función de cada bloque.
