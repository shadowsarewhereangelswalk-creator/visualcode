# UNE2D11 — Etiquetas semánticas: header, nav, main, section y footer

Clase 11 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar una estructura semántica básica de página.
- **Conceptos:** `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Organizar una página sencilla usando cada etiqueta según su función.
- **Archivo:** `index.html`.

Abre `index.html` y revisa cómo cada zona de la página queda representada con una etiqueta semántica específica.
