# UNE7D07 — Fundamentos de consola psql y comandos básicos

Clase 7 del Nivel 7 — PostgreSQL.

- **Objetivo:** Comprender y aplicar fundamentos de consola psql y comandos básicos dentro del objetivo del Nivel 7.
- **Conceptos:** Fundamentos de consola psql y comandos básicos
- **Herramientas:** PostgreSQL, psql, pgAdmin, SQL
- **Proyecto del nivel:** Migración a PostgreSQL
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de consola psql y comandos básicos.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql` y `commands.psql`

Abre `database.sql` en pgAdmin o ejecútalo con psql. El archivo recrea únicamente el esquema `une7d07_psql` e incluye estructura, datos y consultas de comprobación terminadas.

## Ejecución en psql

Abre una terminal dentro de esta carpeta y ejecuta:

```bash
psql -d postgres -f commands.psql
```

También puedes ejecutar `database.sql` directamente desde pgAdmin.
