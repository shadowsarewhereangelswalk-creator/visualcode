Las cinco prácticas principales corresponden a las clases 8, 15, 22, 26 y 30. El proyecto final es un servicio Flask con interfaz web, API REST, persistencia, migraciones, pruebas y configuración de despliegue.

Todas las clases incluyen `app.py`, `requirements.txt` y el modo de comprobación `python app.py --check`. Las prácticas que usan base de datos incorporan SQLite de forma local; las clases 15, 20 y 30 incluyen migraciones de Alembic. Las clases 22, 25, 26, 27, 28 y 30 incluyen pruebas automatizadas o preparación de paquetes.
