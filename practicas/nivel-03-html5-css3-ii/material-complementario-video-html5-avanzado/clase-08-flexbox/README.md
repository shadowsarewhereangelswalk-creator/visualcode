# Clase 08 — Flexbox

Video: https://www.youtube.com/watch?v=-dFilq0OrYg

Ejercicios reconstruidos a partir de la transcripción de **HTML5 Nivel 2 — Flexbox**.

## Qué practica

- Flexbox como método de diseño unidimensional en filas o columnas.
- `display: flex` en el contenedor.
- `flex-direction` para cambiar el eje principal.
- Distribución de artículos en columnas de igual altura.
- Salto de elementos a nuevas filas mediante un contenedor con ajuste.
- Uso de `flex: 200px` como tamaño base flexible.
- Proporciones con `flex: 1` y un tercer elemento con proporción `2`.
- Forma abreviada de la propiedad `flex`.
