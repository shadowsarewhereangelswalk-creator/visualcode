# UNE10D27 — Fundamentos de creación y empaquetado de una librería

Clase 27 del Nivel 10 — Python III: Flask.

- **Práctica:** Fundamentos de creación y empaquetado de una librería
- **Resultado terminado:** Librería con estructura src, metadatos, comando de terminal y pruebas.
- **Herramientas:** Python, Flask y Visual Studio Code
- **Proyecto del nivel:** Servicio Flask

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python -m pytest`.
4. Ejecuta `python -m build`.
5. Instala el wheel generado y ejecuta `career-service-info`.
6. Ejecuta `python app.py` para usar la librería en Flask.

Comprueba la estructura y la lógica independiente con `python app.py --check`.
