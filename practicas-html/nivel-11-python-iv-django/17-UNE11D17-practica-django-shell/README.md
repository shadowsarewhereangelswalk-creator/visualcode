# UNE11D17 — Ejercicio guiado de Django Shell

Clase 17 del Nivel 11 — Python IV: Django.

- **Práctica:** Ejercicio guiado de Django Shell
- **Resultado terminado:** Clientes y pedidos con un comando para cargar datos de demostración.
- **Herramientas:** Python, Django ORM y comandos y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Ejecuta `python manage.py cargar_demo` para crear el conjunto de datos práctico.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
