# UNE10D25 — Fundamentos de tests de aplicaciones Flask

Clase 25 del Nivel 10 — Python III: Flask.

- **Práctica:** Fundamentos de tests de aplicaciones Flask
- **Resultado terminado:** Servicio de cálculo con fixtures, cliente de prueba y cobertura.
- **Herramientas:** Python, Flask y Visual Studio Code
- **Proyecto del nivel:** Servicio Flask

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python -m pytest`.
4. Ejecuta `python app.py` para usar el servicio.

Comprueba la estructura y la lógica independiente con `python app.py --check`.
