# UNE6D02 — Fundamentos de modelo relacional y diseño de una base de datos

Clase 2 del Nivel 6 — MySQL.

- **Objetivo:** Comprender y aplicar fundamentos de modelo relacional y diseño de una base de datos dentro del objetivo del Nivel 6.
- **Conceptos:** Fundamentos de modelo relacional y diseño de una base de datos
- **Herramientas:** MySQL, MySQL Workbench, SQL
- **Proyecto del nivel:** Base de datos para aplicación real
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de modelo relacional y diseño de una base de datos.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en MySQL Workbench y ejecuta todo el script. El archivo recrea únicamente la base `une6d02_relational` e incluye estructura, datos y consultas de comprobación terminadas.
