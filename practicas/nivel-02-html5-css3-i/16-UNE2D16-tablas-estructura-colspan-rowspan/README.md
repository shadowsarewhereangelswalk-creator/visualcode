# UNE2D16 — thead, tbody, tfoot, colspan y rowspan

Clase 16 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar estructura avanzada de tablas.
- **Conceptos:** `<thead>`, `<tbody>`, `<tfoot>`, `colspan` y `rowspan`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Organizar una tabla por secciones y combinar celdas horizontal y verticalmente.
- **Archivo:** `index.html`.

Abre `index.html` y observa qué celdas ocupan más de una columna o más de una fila.
