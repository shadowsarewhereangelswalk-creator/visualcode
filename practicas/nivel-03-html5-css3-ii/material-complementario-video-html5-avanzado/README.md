## Cómo ejecutar

Abre cualquiera de los archivos HTML directamente en el navegador. Para geolocalización y cámara, utiliza preferiblemente localhost o HTTPS, porque los navegadores restringen estas APIs en contextos no seguros.

El ejemplo de WebSocket permite escribir la URL de un servidor WebSocket. El ejemplo de WebRTC realiza una conexión de prueba dentro de la misma página y requiere permiso para usar la cámara.

Los recursos de audio y video usan los archivos CC0 de los ejemplos interactivos de MDN, igual que el material multimedia existente en el Nivel 2.
