# UNE12D07 — Ejercicio guiado de pruebas unitarias con pytest

Clase 7 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Ejercicio guiado de pruebas unitarias con pytest
- **Resultado terminado:** Validación de usuarios y progreso con parametrización, aproximaciones y errores.
- **Herramientas:** pytest y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
