# Nivel 12 — Testing, buenas prácticas y despliegue

El nivel contiene 30 clases (`UNE12D01`–`UNE12D30`) sobre pruebas, calidad, Git, CI/CD, Docker y despliegue.

La práctica final es [UNE12D30 — P5: despliegue de una aplicación Flask en la nube](30-UNE12D30-practica-p5-despliegue-nube/README.md).

El repositorio contiene una solución de referencia y configuración reproducible. La evidencia de un despliegue real (URL, capturas o proveedor) debe registrarse aparte cuando la clase lo solicite.
