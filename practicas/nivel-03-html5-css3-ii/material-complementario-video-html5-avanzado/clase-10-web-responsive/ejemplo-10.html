APIs para el desarrollo de aplicaciones en HTML5

A continuación se muestran algunas interfaces estudiadas durante el curso.

Geolocalización

Permite solicitar la posición del dispositivo con permiso del usuario.

Web Storage

Permite guardar datos mediante localStorage y sessionStorage.

Drag and Drop

Permite arrastrar elementos y soltarlos en zonas habilitadas.

Canvas

Permite dibujar gráficos mediante JavaScript.

Prueba responsive

Abre las herramientas de desarrollo y cambia el ancho o selecciona un dispositivo.

Para observar el diseño adaptativo, usa la opción de inspección del navegador y selecciona un dispositivo.
