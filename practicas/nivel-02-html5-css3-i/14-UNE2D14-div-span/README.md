# UNE2D14 — Contenedores div y span

Clase 14 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar los contenedores `<div>` y `<span>`.
- **Conceptos:** elementos de bloque e inline; comparación del comportamiento inicial de `<div>` y `<p>`; estilos aplicados con CSS.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Comparar dos `div`, dos párrafos y un `span`, y observar cómo CSS puede modificar su presentación.
- **Archivo:** `index.html`.

Abre `index.html` en el navegador y compara la separación predeterminada de los párrafos con la de los `div`.
