# Clase 04 — Audio, video, source y track

Ejercicio reconstruido a partir de la clase **HTML5 Nivel 2 — Audio y Video**.

## Qué practica

- Estructura semántica con `header`, `nav`, `section`, `aside` y `footer`.
- Reproducción nativa con `audio` y `video`.
- Atributo `controls`.
- Múltiples fuentes con `source` para que el navegador seleccione un formato compatible.
- Pistas de subtítulos con `track` y archivos WebVTT.
- Dos pistas de idioma: español e inglés.
- CSS externo y reproductores al 100% del contenedor.
- Menú con enlaces a la documentación de MDN para audio, video, source y track.

## Archivos

- `ejemplo-04.html`
- `estilos.css`
- `track/ejemplo-04.vtt`
- `track/ejemplo-04-ingles.vtt`

El video y el audio usan recursos CC0 de los ejemplos interactivos de MDN para que el ejercicio funcione sin almacenar archivos multimedia binarios en el repositorio.
