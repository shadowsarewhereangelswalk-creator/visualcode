# Clase 10 — Diseño web responsive

Video: https://www.youtube.com/watch?v=85akbLU7TAg

Ejercicio reconstruido a partir de la transcripción de **HTML5 Nivel 2 — Diseño Web Responsive**.

## Qué practica

- Responsive Web Design para adaptar la presentación a diferentes anchos.
- `meta name="viewport"` con `width=device-width` e `initial-scale=1`.
- Enfoque móvil primero: columnas al 100 %.
- División conceptual del ancho en 12 columnas.
- Medidas relativas basadas en aproximadamente 8,33 % por columna.
- Clases para tablet (`col-s-*`) y PC (`col-*`).
- Media query para tablet desde 600 px.
- Media query para PC desde 768 px.
- Estructura de encabezado, fila principal, navegación, contenido y pie.
- Prueba del diseño con las herramientas de dispositivo del navegador.
