# UNE6D24 — Ejercicio guiado de procedimientos almacenados

Clase 24 del Nivel 6 — MySQL.

- **Objetivo:** Comprender y aplicar ejercicio guiado de procedimientos almacenados dentro del objetivo del Nivel 6.
- **Conceptos:** Ejercicio guiado de procedimientos almacenados
- **Herramientas:** MySQL, MySQL Workbench, SQL
- **Proyecto del nivel:** Base de datos para aplicación real
- **Ejercicio:** Realizar un ejemplo guiado de ejercicio guiado de procedimientos almacenados.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.

Abre `database.sql` en MySQL Workbench y ejecuta todo el script. El archivo recrea únicamente la base `une6d24_enrollment` e incluye estructura, datos y consultas de comprobación terminadas.
