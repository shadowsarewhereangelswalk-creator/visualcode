# UNE12D03 — Ejercicio guiado de principios de testing y pirámide de pruebas

Clase 3 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Ejercicio guiado de principios de testing y pirámide de pruebas
- **Resultado terminado:** Sistema de inventario, pago y pedidos cubierto en los tres niveles de la pirámide.
- **Herramientas:** pytest, mocks y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
