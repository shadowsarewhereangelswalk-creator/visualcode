# UNE7D04 — Fundamentos de instalación y configuración de PostgreSQL

Clase 4 del Nivel 7 — PostgreSQL.

- **Objetivo:** Comprender y aplicar fundamentos de instalación y configuración de postgresql dentro del objetivo del Nivel 7.
- **Conceptos:** Fundamentos de instalación y configuración de PostgreSQL
- **Herramientas:** PostgreSQL, psql, pgAdmin, SQL
- **Proyecto del nivel:** Migración a PostgreSQL
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de instalación y configuración de postgresql.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en pgAdmin o ejecútalo con psql. El archivo recrea únicamente el esquema `une7d04_environment` e incluye estructura, datos y consultas de comprobación terminadas.
