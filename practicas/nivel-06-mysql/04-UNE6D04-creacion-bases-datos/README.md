# UNE6D04 — Fundamentos de creación de bases de datos

Clase 4 del Nivel 6 — MySQL.

- **Objetivo:** Comprender y aplicar fundamentos de creación de bases de datos dentro del objetivo del Nivel 6.
- **Conceptos:** Fundamentos de creación de bases de datos
- **Herramientas:** MySQL, MySQL Workbench, SQL
- **Proyecto del nivel:** Base de datos para aplicación real
- **Ejercicio:** Realizar un ejemplo guiado de fundamentos de creación de bases de datos.
- **Entregable:** Resolver una práctica corta y responder preguntas de comprobación.
- **Archivos:** `database.sql`

Abre `database.sql` en MySQL Workbench y ejecuta todo el script. El archivo recrea únicamente la base `une6d04_workspace` e incluye estructura, datos y consultas de comprobación terminadas.
