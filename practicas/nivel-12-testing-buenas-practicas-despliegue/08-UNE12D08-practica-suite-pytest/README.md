# UNE12D08 — Práctica P1: suite de pruebas unitarias con pytest para un proyecto propio

Clase 8 del Nivel 12 — Testing, buenas prácticas y despliegue.

- **Práctica:** Práctica P1: suite de pruebas unitarias con pytest para un proyecto propio
- **Resultado terminado:** Gestor persistente de tareas acompañado por una suite exhaustiva de pytest.
- **Herramientas:** pytest, JSON y Python y Visual Studio Code
- **Proyecto del nivel:** Aplicación desplegada

1. Crea el entorno con `python -m venv .venv`.
2. Activa el entorno virtual.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Ejecuta `python -m pytest`.

Comprueba la estructura con `python app.py --check`.
