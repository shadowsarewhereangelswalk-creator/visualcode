# UNE2D15 — Tablas: table, tr, th y td

Clase 15 del Nivel 2 — HTML5 y CSS3 Nivel I.

- **Objetivo:** Comprender y aplicar una tabla HTML básica.
- **Conceptos:** `<table>`, `<tr>`, `<th>` y `<td>`.
- **Herramientas:** HTML5, CSS3, VS Code y navegador.
- **Proyecto asociado:** Landing page estática.
- **Práctica:** Construir una tabla sencilla con encabezados y varias filas de datos.
- **Archivo:** `index.html`.

Abre `index.html` y relaciona cada fila y cada celda con la etiqueta que la representa.
