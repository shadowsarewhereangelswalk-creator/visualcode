# UNE11D01 — Introducción al Nivel 11: objetivos, herramientas y proyecto del mes

Clase 1 del Nivel 11 — Python IV: Django.

- **Práctica:** Introducción al Nivel 11: objetivos, herramientas y proyecto del mes
- **Resultado terminado:** Panel JSON con la ruta práctica del nivel.
- **Herramientas:** Python, Django y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
