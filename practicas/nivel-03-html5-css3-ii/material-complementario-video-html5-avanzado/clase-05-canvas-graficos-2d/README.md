# Clase 05 — Canvas y gráficos 2D

Ejercicio reconstruido a partir de la clase **HTML5 Nivel 2 — Canvas y Gráficos 2D**.

## Qué practica

- Creación de un `canvas` con ancho y alto definidos.
- Selección del elemento con `document.getElementById`.
- Obtención del contexto con `getContext("2d")`.
- Uso de `fillStyle` y `fillRect(x, y, ancho, alto)`.
- Arreglo de colores.
- Ciclo `for` para generar varios rectángulos.
- Incremento de coordenadas `x` e `y` en 100 píxeles.
- Uso de `sort()` para comprobar que el resultado depende de los datos procesados por JavaScript.
