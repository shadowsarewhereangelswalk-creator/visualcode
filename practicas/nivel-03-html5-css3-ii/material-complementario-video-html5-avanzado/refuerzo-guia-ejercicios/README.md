# Refuerzo basado en la guía HTML5

Esta carpeta contiene ejercicios **derivados** de la guía entregada junto con las clases. No es una transcripción literal de la guía ni una copia del PDF.

La guía incluye, entre otros contenidos, ejemplos de estilo con CSS3, un efecto acordeón HTML+CSS, fijación de estructura semántica e introducción al diseño responsive. Estos ejercicios conectan ese material con las clases 07–10.

## Ejercicio 01 — CSS3 + acordeón

Archivos:

- `01-acordeon-css3.html`
- `refuerzo.css`

Objetivos:

1. Estilizar una tarjeta con borde redondeado, sombra y degradado.
2. Crear secciones desplegables tipo acordeón.
3. Aplicar un efecto de transformación al pasar el puntero.
4. Identificar qué reglas corresponden a estructura y cuáles a presentación.

## Ejercicio 02 — estructura semántica responsive

Archivo:

- `02-estructura-semantica-responsive.html`
- `refuerzo.css`

Objetivos:

1. Reforzar `header`, `nav`, `main`, `section`, `aside` y `footer`.
2. Distribuir las tarjetas con Flexbox.
3. Adaptar la interfaz para móvil y escritorio.
4. Relacionar estructura semántica, Flexbox y responsive design.

## Desafíos de conexión con las clases

- **Clase 07:** añade dos selectores de atributo al acordeón.
- **Clase 08:** cambia la dirección del contenedor entre fila y columna y compara el resultado.
- **Clase 09:** convierte una tarjeta del ejercicio 02 en elemento arrastrable y crea una zona de destino.
- **Clase 10:** prueba el ejercicio 02 a 360 px, 600 px y 768 px o más.

La guía también repasa Canvas, audio y video; esos contenidos ya tienen ejercicios específicos en las clases 04 y 05 de este material complementario.
