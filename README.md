# Prácticas de HTML — AI Career

Este repositorio se trabajará desde cero y contendrá únicamente prácticas de HTML.

Las prácticas se agregarán una por una. No se publicará la siguiente hasta que Karen confirme que desea continuar.

## Práctica disponible

1. [Página con etiquetas básicas de texto](practicas-html/01-etiquetas-basicas/README.md)

## Forma de trabajo

1. Lee las instrucciones de la práctica.
2. Abre el archivo inicial en Visual Studio Code.
3. Completa el ejercicio con tus propias palabras.
4. Revisa el resultado en el navegador.
5. Comparte el código o una captura para revisarlo.
