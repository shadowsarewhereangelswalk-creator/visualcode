# UNE11D03 — Ejercicio guiado de instalación, proyecto y servidor de desarrollo de Django

Clase 3 del Nivel 11 — Python IV: Django.

- **Práctica:** Ejercicio guiado de instalación, proyecto y servidor de desarrollo de Django
- **Resultado terminado:** Portal Django completo con plantilla y estilos.
- **Herramientas:** Python, Django, templates y archivos estáticos y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
