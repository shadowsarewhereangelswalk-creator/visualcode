# UNE11D27 — Fundamentos de CRUD completo con Django

Clase 27 del Nivel 11 — Python IV: Django.

- **Práctica:** Fundamentos de CRUD completo con Django
- **Resultado terminado:** Catálogo con CRUD completo mediante vistas genéricas.
- **Herramientas:** Python, Django ORM, formularios y vistas genéricas y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
