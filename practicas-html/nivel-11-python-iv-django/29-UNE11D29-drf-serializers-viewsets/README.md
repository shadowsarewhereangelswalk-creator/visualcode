# UNE11D29 — Fundamentos de Django REST Framework: serializers y viewsets

Clase 29 del Nivel 11 — Python IV: Django.

- **Práctica:** Fundamentos de Django REST Framework: serializers y viewsets
- **Resultado terminado:** API relacionada de clientes y proyectos con serializers, viewsets y acción resumen.
- **Herramientas:** Python, Django REST Framework y Visual Studio Code
- **Proyecto del nivel:** Aplicación Django

1. Crea y activa un entorno virtual.
2. Ejecuta `python -m pip install -r requirements.txt`.
3. Ejecuta `python manage.py migrate`.
4. Ejecuta `python manage.py runserver`.

Ejecuta `python manage.py test core` para comprobar la práctica automatizada.

Comprueba la estructura con `python manage.py --check` y el proyecto con `python manage.py check`.
