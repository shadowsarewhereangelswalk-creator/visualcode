Fundamentos de Box Model: contenido, padding, border y margin

Las cuatro áreas del Box Model

Contenido
Content
El texto o elemento central.
Padding
El espacio interior alrededor del contenido.
Border
La línea que rodea el padding y el contenido.
Margin
El espacio exterior que separa el elemento de otros.
